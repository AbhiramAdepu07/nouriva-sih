♻️ If Food Was Rescued

If suitable edible surplus is safely redistributed instead of being discarded, the associated emissions can be represented as potentially avoided.


🌱 Potentially avoided: 0 kg CO₂e

Example

10 kg food waste × 2.5 kg CO₂e/kg


= 25 kg CO₂e estimated impact


The 2.5 factor is an illustrative prototype value. A production system should use appropriate food-specific life-cycle emission factors.
